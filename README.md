# JavaScript Practice Set

10 HackerRank-style practice questions (8 JavaScript, 1 HTML, 1 CSS) with an in-browser editor and automatic tests.

- Write your code and press **Run tests** (or Ctrl+Enter)
- Some tests are **hidden**, like on HackerRank, so think about edge cases
- JavaScript runs in a Web Worker with a **3-second time limit**, so slow solutions fail
- Hints and solutions for every question
- Optional 60-minute timer
- Your code and progress are saved in your browser

Open `index.html` locally or view it on GitHub Pages.
